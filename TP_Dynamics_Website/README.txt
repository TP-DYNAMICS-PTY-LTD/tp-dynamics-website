TP DYNAMICS WEBSITE
====================

This version was redesigned from the supplied TP Dynamics poster/template.

FOLDER STRUCTURE
----------------
index.html
css/style.css
js/script.js
images/tp-dynamics-logo.jpg
images/tp-laptop.jpg

FEATURES
--------
- Responsive modern TP Dynamics design
- Black, white and gold visual identity matching the supplied artwork
- Mobile navigation
- Animated scroll reveal
- Scroll progress indicator
- Service cards with working detail popups
- Contact form that opens a pre-filled WhatsApp enquiry
- Click-to-call and WhatsApp buttons
- Responsive tablet/mobile layouts
- Back-to-top button

HOW TO RUN
----------
1. Extract the folder.
2. Open index.html in Chrome/Edge/Firefox.
3. No server is required for the front-end demo.
